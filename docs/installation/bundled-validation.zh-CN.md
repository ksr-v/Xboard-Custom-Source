## 2026.10.18.3 已验证的修补

本次修补继续使用授权测试虚拟机 `192.168.128.129` 的隔离 PHP-FPM / SQLite 站点，已验证以下实际流程：

```bash
  XBOARD_TEST_VENDOR=/本地依赖/vendor/autoload.php \

  php tests/BundledPlugins/integration.php

  XBOARD_TEST_VENDOR=/本地依赖/vendor/autoload.php \
  php tests/BundledPlugins/update_retry.php

```
