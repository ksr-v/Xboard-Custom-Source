## 适用与保全边界

本版新站目标是 Linux、systemd、aaPanel / 宝塔、原生 PHP-FPM、Nginx / OpenResty、MySQL / MariaDB 与 Redis。五插件在全新应用安装时自动安装启用；Root 初始化随后配置入口与助手。显式 `--skip-endpoint` 仍将入口、公共 CA 与助手延期。

以 Root 执行归档升级且不传 `--skip-endpoint`，会为已有有效原生入口安装或更新助手，其网站 UID、固定任务和允许端口授权范围与新初始化相同；仅插件上传、手动源码升级或明确跳过而助手仍缺失时，才需单独 `--enable-web-manager`。这属于 Root 安装/升级协调器的行为，不是网页自行创建服务；本轮候选归档已按默认流程完成上述升级与保全演练。

旧站升级保留 `.env` / APP_KEY、业务数据、机器身份、CA、插件配置与管理员禁用选择。助手按网站系统 UID 授权，同一 UID 下的站点共享信任边界；生产多站应配置独立 UID，且 FPM 与 CLI 身份一致。未知部署、未批准端口、根 CA 轮换和私钥导出保留 SSH 审阅与处理。

本轮尚未把 Docker / Octane 整套部署、真实 Node WSS、代理内核流量、外部客户端扫码、ARM64、长期负载或生产迁移计作已完成验证。网站域名 HTTPS / Cloudflare 配置和独立节点私有 CA 分别核验，网页操作成功也不等于实际 Node 已完成认证或 WSS 连接。
