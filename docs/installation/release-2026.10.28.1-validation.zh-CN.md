Node 修复从 `v1.13-orphan.6` / `9394b235fe0665ab6e29a2281b9295a9fc5ddeaf` 开发。先前 B7 构建的双内核完整矩阵为 20 个案例、69 项断言。最终 retain 修复源码完成全部 `internal/...` 的 489 项 race test/subtest，修复候选二进制的定向验收为 9 个案例、31 项断言。

这些测试覆盖正常断开、客户端黑洞、节点暂停、超过 300 秒的长连接、反向 IP、双向跨节点争抢、同时争抢、动态限额与面板失联保护。最终候选二进制与 B7 的摘要不同，未把 B7 全矩阵直接归属最终构建。正式 `v1.13-orphan.7` 的构建摘要和复测由对应 Node Release 记录。

实际链路为 VLESS/TCP、REST 面板通信和不同 loopback 来源 IP；未覆盖全部协议、外部 NAT/CDN、ARM64、真实 WS 网络握手及生产迁移。
