# 2026.10.31.2：独立插件最新发行与统一升级

节点新增对接继续默认最新正式版，不固定 orphan 编号。已运行的节点仍需在各自机器升级。

插件管理页的五个功能插件分别读取固定官方仓库的最新稳定插件发行；七个核心插件读取面板正式发行。每次更新固定所选发行并验证真实提交、归档摘要、插件身份和全部文件；预发布、错误摘要或缺失的新发行不会悄悄回退为旧包。检查结果短时缓存，实际更新使用新取得并固定的来源。

内置二维码源码更新为官方 1.3.1，保留此前已安装的 1.3.1 数据库记录。升级清理会保护二维码私有存储；配置和管理员启停选择保持原样。独立安装的同版本正式源码及已审核的完整运行时修正不会被旧面板快照覆盖。

SSH 升级器在面板更新后逐项检查、更新已安装的官方插件，最终验证实际目标版本、原配置和启停状态。PHP-FPM 重载支持主进程 PID 改变，核对本次启动日志、配置和工作进程后，再刷新已识别的本站常驻进程并退出维护。失败会保留维护状态、备份和阶段记录；临时下载及凭据文件自动删除。

执行方式、固定文件摘要和本次测试记录随正式发行附件提供。网页更新只更新选中的插件；面板与全部官方插件的升级使用 SSH 升级器。
