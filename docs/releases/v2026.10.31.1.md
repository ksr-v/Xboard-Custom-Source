# 2026.10.31.1 本地候选：默认最新节点与插件在线更新

此版本已在本地实现并验证，尚未发布或部署。

- NodeEndpoint 升至 1.1.3。机器管理的域名/IP 新装命令使用独立 Node 仓库的最新正式安装器，不再固定 orphan.7、orphan.9 或任何后续 orphan 编号。
- 独立节点通讯页的新增对接命令默认选择最新正式 Release；准备时固定所选 tag，安装时复核同一发行的摘要、架构和程序版本。网络或校验失败立即停止。已有实例仍沿用迁移流程。
- 插件管理页自动检查更新，提供“检查插件更新”和“一键更新最新版”。五个内置功能插件及七个核心插件均支持在线更新。第三方上传插件沿用手动上传。
- 从同一正式面板发行取得并校验归档和来源锁，只更新选中的插件，保留配置与启停选择。同版源码修复也可更新；较新的本地版本不会降级。
- 更新使用独立 PHP 进程和原子源码替换，保留恢复备份。普通插件写操作与在线更新共用互斥锁，避免其他标签页同时修改配置。
- 内置插件同步接受经过校验的同版历史源码快照；拒绝未知修改和文件混拼，并保留较新的在线源码。

操作及备份路径见[插件在线更新说明](../operations/plugin-online-update.zh-CN.md)。

验证：节点相关 90 项、插件在线更新 10 项、同版本快照 10 项、内置插件集成 29 项、实际 Admin 网页交互 8 项通过。内置插件集成在 PHP 8.2 / SQLite 下执行；历史 SubInfoCustomizer 1.0.0 原生安装要求 PHP 8.3，该单项跳过。下载和新版节点选择使用受控发行样本，未执行真实线上更新。
