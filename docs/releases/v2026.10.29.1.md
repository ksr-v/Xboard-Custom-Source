# v2026.10.29.1：默认加入订阅信息管理

本版将 SubInfoCustomizer `1.0.1` 纳入默认插件清单。全新安装会自动安装并启用全部五项；已有面板升级时，缺少该插件会安装并启用，已独立安装官方 `1.0.0` 的站点会升级并保留模板、配置和管理员禁用选择。

## 默认插件

| 插件 | 版本 |
| --- | --- |
| NodeEndpoint | 1.0.10 |
| SmartExpiry | 1.2.0 |
| QRCode Extend | 1.2.0（审计副本） |
| FlowScope | 2.4.0 |
| SubInfoCustomizer | 1.0.1 |

后台左侧“订阅信息管理”提供 0–4 行全局订阅顶部信息、九个动态变量、排序、单行开关、示例预览和两种日期格式。默认三行展示日期/UID、流量与到期/重置信息。保存后下一次订阅请求生效；禁用插件恢复原生订阅信息逻辑，已保存模板保留。

SubInfoCustomizer `1.0.1` 支持 PHP 8.2 / 8.3 和 Laravel 12，并在安装/启用前明确检查 mbstring。核心控制器摘要和 Admin 结构校验继续生效，未知版本拒绝启用。四个既有插件源码及版本、配套独立 Node `v1.13-orphan.7`、Root installer `v1.0.9` / tools `1.0.6` 均保持原样。

## 升级与保全

默认插件来源锁新增独立仓库固定提交与逐文件 SHA-256，收录官方 SubInfoCustomizer `v1.0.0` 的完整源码摘要。已有已启用/禁用的独立安装均可接管升级；较新版本不降级。未知本地修改会在写入任何插件前拒绝覆盖。普通同步保留管理员选择，只有显式 `--enable-all` 会重新启用已禁用插件。

修复默认插件通过后台完整删除后，残留来源记录阻止下一次更新的问题。默认插件在后续同步时会重新部署；希望长期关闭某项时使用“禁用”，该选择会保留。已存在但文件缺失或修改过的目录继续拒绝覆盖。

升级后重新校验并应用单个订阅桥接，保留其他插件的后台集成、业务数据、公共 CA、APP_KEY 和机器身份。已使用 Node `v1.13-orphan.7` 的机器无需仅为本次插件捆绑重装或更新。

## 安装资产与验证

使用本 Release 的 `xboard.tar.gz`、`SHA256SUMS`、`latest.json`、`plugin-source-lock.json` 和 `VALIDATION.md`。发行包从干净、已提交的源码构建，逐项验证五插件源码锁与 Root 工具固定摘要，排除运行配置、已安装插件、数据库和私钥。

新站参照[本版安装说明](../installation/install-2026.10.29.1.zh-CN.md)，已有原生 PHP-FPM 站点参照[升级说明](../installation/upgrade-2026.10.29.1.zh-CN.md)。具体实测结果、测试环境与未覆盖范围见[本版验证记录](../installation/release-2026.10.29.1-validation.zh-CN.md)。PHP 8.2 CLI 检查不等于 Docker 镜像/Octane 完整部署验收；本版不额外发布未经复验的 Docker 镜像。
