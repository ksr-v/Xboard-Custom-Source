# v2026.10.28.1：在线设备、中心准入与创建用户默认计划

本版将在线设备修复和创建用户默认计划改动合入面板源码。运行基准为 Linux、aaPanel、PHP 8.3、Laravel 12、原生 PHP-FPM、Nginx/OpenResty、MySQL/MariaDB 和 Redis。配套节点版本为独立 `xboard-node v1.13-orphan.7`，按“先面板、后节点”的顺序升级。

## 面板变化

- 在线设备按每账号的来源 IP 去重。完整设备快照更新当前节点；省略快照不表示离线，明确空快照及时清除旧节点的 legacy 记录。
- 新节点通过 Redis Lua 原子准入检查全局 IP 名额，使用 generation token 释放租约。迟到快照、迟到释放和旧 WebSocket 关闭回调不会撤销新连接的有效名额。
- 支持快速心跳的节点采用 60 秒租期；未知旧节点继续保留 300 秒宽限。用户列表在前台约每 5 秒刷新，在线筛选、排序和分页使用校准后的数字；每分钟后台清理过期统计。
- 创建用户时，计划列表异步加载后默认选择 API 返回的首个实际计划。保留管理员手选“无”、其他计划及取消后的草稿；单个和批量创建共用该行为。
- 创建并分配套餐的用户继承该套餐的 `device_limit`，包括正数、`0` 和 `null`；不批量改写已有用户。

## 插件与节点

默认插件仍为独立插件体系中的四项：NodeEndpoint、SmartExpiry、QRCodeExtend、FlowScope。后三项业务源码和版本保持原样；NodeEndpoint 本次配套版本为 `1.0.10`，新机器安装入口固定 Node `v1.13-orphan.7`，不重建原 CA 或改变机器身份。

SubInfoCustomizer 继续单独安装和发布，不加入四插件捆绑清单。已有插件配置、公共 CA、APP_KEY、机器绑定和管理员启停选择按原升级流程保留。

所有需要严格跨节点限额的节点都应升级。旧节点不调用中心准入，混用时不能承诺严格的全局限额。在线“设备”是来源 IP，不能区分同一 NAT 出口后的多台物理设备。

## 安装包

使用本 Release 的 `xboard.tar.gz` 和 `SHA256SUMS`。同时提供 `latest.json`、`plugin-source-lock.json` 与 `VALIDATION.md`，记录准确源码提交、构建标识、文件大小、摘要及验证边界。构建标识采用提交时间的 UTC 日期加短 SHA，与本页的人类可读 tag 分开记录。

安装包不含 `.env`、运行数据、vendor 或已安装插件目录；从锁定的 `composer.lock` 安装依赖，默认插件按捆绑清单逐文件校验后部署。

新建空站使用[本版安装教程](https://github.com/ksr-v/Xboard-Custom-Source/blob/v2026.10.28.1/docs/installation/install-2026.10.28.1.zh-CN.md)；已有 aaPanel/PHP-FPM 面板使用[升级说明](https://github.com/ksr-v/Xboard-Custom-Source/blob/v2026.10.28.1/docs/installation/upgrade-2026.10.28.1.zh-CN.md)。不要在已有数据库重新执行全新安装或生成 APP_KEY。
